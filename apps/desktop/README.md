# OpenScript Desktop App

Coming soon! This will be the desktop application for OpenScript.

- **Framework**: Electron or Tauri
- **Video Processing**: FFmpeg.wasm
- **Transcription**: Whisper (transformers.js)
- **UI**: React + Tailwind CSS

## Features (Planned)

- Local video file processing
- Automatic transcription
- Text-based editing
- Real-time preview
- Export in multiple formats
